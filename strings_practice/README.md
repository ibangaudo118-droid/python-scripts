# Strings Practice

## What it does
This script stores string values and demonstrates their conversion using `.upper()`, `.lower()`, and `.strip()`. It also demonstrates how to extract specific characters using indexing and slicing.

## How to run it
In Termux, run:
python strings_practice.py

## What I learned
- I learned how to use string methods like `.upper()` and `.lower()` to change the case of text.
- I learned how to use `.strip()` to remove extra spaces from the beginning and end of a string.
- I learned how to use indexing (like `[0]`) to get a single character, and slicing (like `[6:11]`) to get a specific section of text.

## What broke and how I fixed it
When demonstrating the `.strip()` method, I accidentally printed the wrong variable (I printed `full_name` instead of `sentence`). I fixed it by changing the print statement to output the `sentence` variable so I could actually see the spaces were removed.
