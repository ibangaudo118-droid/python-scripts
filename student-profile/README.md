# Student Profile Recorder

## What it does
This program stores basic information about a student and prints it to the terminal in a clean, readable format.

## How to run it
Open Termux, navigate to this folder, and run:
python student_profile.py

## Data Types Used
- `str` (String): Used for `student_name`.
- `int` (Integer): Used for `student_age`.
- `float` (Float): Used for `student_CGPA`.
- `bool` (Boolean): Used for `university_status` (True/False).

## What I learned
1. How to use f-strings (f"") to insert variables directly into a print statement.
2. How to use different data types (int, float, str, bool) to store specific kinds of information.
