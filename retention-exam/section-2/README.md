# Expense Tracker

A command-line expense tracker built with Python.

## Features
- Add expenses.
- View all expenses.
- Remove expenses by amount.
- Calculate total spending.
- Handle invalid inputs.
- Uses functions to organise program operations.

## Concepts Practised
- Variables and data types
- Lists
- While loops
- Conditional statements
- Functions
- Parameters and arguments
- Return values
- Exception handling
