# Operators Practice

## What it does
This script demonstrates the use of Arithmetic, Logical, Comparison, and Assignment operators using two variables.

## How to run it
In Termux, run:
python operators_practice.py

## What I learned
- I learned how to use the `not` operator by placing it before a parenthesized comparison expression, like `if not (comparison_expression)`.

## What broke and how I fixed it
I initially wrote code that looked like `if number1 < number2 and number2 not number1:`. A SyntaxError was displayed. I fixed it by rewriting the code to properly use parentheses with the `not` operator, like `if not (comparison_expression)`.
