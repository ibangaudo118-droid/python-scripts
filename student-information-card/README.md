# Student Information Card

## What it does
This program interacts with the user by asking for their personal and academic details. It then displays the collected information neatly formatted as a student information card.

## How to run it
In Termux, run:
python student_information_card.py

## What I learned
- I learned how to use the `input()` function to collect data directly from the user.
- I learned that `input()` always returns a string (`str`), which means even if the user types a number for their age, Python treats it as text unless I explicitly convert it.
- I practiced using `f-strings` to dynamically format and display the collected variables.

## What broke and how I fixed it
Nothing broke during the final run. The code executed successfully.
