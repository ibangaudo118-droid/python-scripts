# List Comprehensions Practice

## What it does
This script takes an existing list of numbers and uses a list comprehension to generate a new list where every number is multiplied by two. It then prints both the original and the doubled lists.

## How to run it
In Termux, run:
python list_comprehensions.py

## What I learned
- I learned that a list comprehension is a shorter, cleaner way to create a new list from an existing one.
- I learned the syntax: `[expression for item in iterable]`. The expression is what happens to the item, and the `for` part loops through the original list.
- I learned that I can do the work of a `for` loop and an `.append()` in a single line of code.
