# Calculator Functions

## What it does
This program takes two numbers from the user and performs a selected arithmetic operation (addition, subtraction, multiplication, or division). It uses separate functions for each operation and returns the calculated result to be displayed.

## How to run it
In Termux, run:
python calculator_functions.py

## What I learned
- I learned how to define functions using `def` and pass parameters (`a`, `b`) into them.
- I learned how to use the `return` keyword to send the result of a calculation back to the main program.
- I learned how to call a function based on user input using `if/elif` statements.
- I learned how to use `float()` so the calculator can handle decimal numbers, and `round()` to format the division result to two decimal places.
